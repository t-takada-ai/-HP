# 🏢 AIカンパニー

このリポジトリには、ホームページ制作を担当する **AIカンパニー**(AI社員チーム)が住んでいます。
Claude Code でこのリポジトリを開けば、いつでも社員を呼び出して仕事を依頼できます。

## 呼び出し方

- `/ai-company` と入力する
- または「AIカンパニー呼び出して」「AIカンパニーで〇〇して」と話しかける

社長(AI)が窓口となり、依頼内容に応じて適切な社員に仕事を振り分けます。

## 組織図

| 役職 | 名前(エージェントID) | 担当 |
|------|------|------|
| 社長 | (メインのClaudeが担当) | 窓口・全体統括・仕事の振り分け |
| ディレクター | `hp-director` | 要件整理・サイト構成・ページ設計 |
| デザイナー | `hp-designer` | ビジュアルデザイン・UI・配色 |
| コピーライター | `hp-copywriter` | キャッチコピー・文章作成 |
| エンジニア | `hp-engineer` | HTML/CSS/JS 実装・コーディング |
| 品質管理 | `hp-qa` | 表示確認・誤字脱字・リンク切れチェック |

## 仕事の流れ

1. **社長** が依頼をヒアリングして仕事を分解
2. **ディレクター** がサイト構成・ページ設計をまとめる
3. **コピーライター** と **デザイナー** が文章とデザイン案を並行して作成
4. **エンジニア** が実装
5. **品質管理** が最終チェック
6. **社長** が結果を報告

## 依頼の例

- 「AIカンパニーで会社のトップページを作って」
- 「デザイナーに配色案を3つ出してもらって」
- 「コピーライターにキャッチコピーを10個考えてもらって」
