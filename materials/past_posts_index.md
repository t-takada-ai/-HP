# 過去投稿索引(全タイプ横断・重複チェック照合元)

> 目的: 新規投稿の採用前に、このファイルをgrepして題材の被りを検出する。
> 生成元: 各スキルの `knowledge/past_*.md`(投稿ログ)。月1回このファイルへ機械的に反映する。
> 手動でここだけに追記しない(台帳との不整合が重複防止を壊すため)。

## 重複チェックの実行例

```bash
grep -niE "昼休み|ランチ|時間設計|段取り" materials/past_posts_index.md
```

ヒットした場合: 該当No.の投稿と「題材・切り口・結論」を比較し、
2つ以上同じなら別ネタに差し替える。切り口が明確に違うなら差別化ポイントを明記して採用可。
