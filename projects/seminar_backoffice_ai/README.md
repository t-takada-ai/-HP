# AIバックオフィス業務効率化セミナー(90分・経営者向け)

商工会議所・経営者団体主催を想定した、中小企業の経営者・役員向けセミナー資料一式。

## ファイル

| ファイル | 内容 |
|---|---|
| `AIバックオフィス業務効率化セミナー_90分_v1.pptx` | 本編スライド 全70枚(スピーカーノート付き) |
| `骨子_v1.md` | 確定骨子(構成・設計方針・時間配分) |
| `generator/` | スライド生成スクリプト(pptxgenjs)。再生成・部分修正用 |

## セミナー概要

- **タイトル**:人を増やさずに、事務は回る。
- **対象**:中小企業の経営者・役員
- **目的**:危機感と意欲向上(今やらないとまずい、と腹落ちさせる)
- **尺**:90分(講義80分＋質疑10分)/ ワークなし
- **構成**:全70枚 / 6部構成

| 部 | 内容 | 枚数 | 時間 |
|---|---|---|---|
| 第0部 | オープニング | 4枚 | 3分 |
| 第1部 | 事務が回らなくなる日(危機感) | 12枚 | 14分 |
| 第2部 | AIは何をしてくれるのか(理解) | 10枚 | 11分 |
| 第3部 | どの業務が変わるのか(業務別) | 18枚 | 22分 |
| 第4部 | やった会社と、やらなかった会社 | 8枚 | 9分 |
| 第5部 | 社長は何を決めるのか(実践) | 12枚 | 15分 |
| 第6部 | 持ち帰っていただくこと | 6枚 | 6分 |

## 登壇前に差し替えが必要な箇所

| スライド | 内容 |
|---|---|
| 1, 4 | 登壇者名・所属・肩書き |
| 6, 8 | 人手不足感・生産年齢人口の推移(登壇時点の最新統計へ) |
| 13, 20, 25, 29, 42, 46 | 試算・イメージ図(自社/主催地域の実データがあれば差し替え) |
| 47〜49 | 事例A・B・C(想定事例。自社の導入実績があれば差し替え) |
| 64 | 公的支援制度(年度ごとに要件が変わるため要確認) |
| 70 | 主催者の相談窓口・講師連絡先 |

数値スライドには「※イメージ」「※試算例」の注記を入れてある。実データに差し替えた場合は注記も外すこと。

## 併せて用意すると効果が上がる配布物

- 業務棚卸しシート(「探す・書く・転記・確認」の4分類で記録する A4・1枚)
- 社内ルールのひな形(スライド62の3項目 / A4・1枚)

スライド55・68がこの2点の使用を前提にした構成になっている。

## スライドの再生成

```bash
cd generator
npm install pptxgenjs react-icons react react-dom sharp
node build.js ../AIバックオフィス業務効率化セミナー_90分_v1.pptx
python3 overflow.py ../AIバックオフィス業務効率化セミナー_90分_v1.pptx   # テキスト溢れ検査
```

`build.js` が本文・構成、`lib.js` がデザインシステム(Midnight Executive / ネイビー `1E2761`・アイスブルー `CADCFC`)、
`icons.js` がアイコン生成を担当。日本語の行送りを見積もって自動でフォントサイズを詰めるため、
文言を長くしても文字が枠外に出ない作りになっている。
