# 【骨子ドラフト v1】AI業務効率化セミナー(バックオフィス主体)

タイトル：**人を増やさずに、事務は回る。**
副題：中小企業の経営者が今日から決めるAI活用の第一歩
対象：中小企業の経営者・役員(商工会議所・経営者団体の主催セミナー)
目的：**危機感と意欲向上** — 「今やらないとまずい」と腹落ちさせ、動き出す気にさせる
想定枚数：70枚 / 90分(講義80分 + 質疑10分・ワークなし)

## 設計方針

- **前半で危機感 → 中盤で理解 → 後半で"経営者がやること"** の3段構え。危機感が目的なので第1部に厚みを持たせる
- ワークがないぶん、**Qページ(問いかけ)を約8枚挟んで「自分ごと化」の間**を作る。手は動かさないが頭は止める
- 経営者向けなので**ツール操作は扱わない**。「何ができるか」ではなく「何が変わるか・いくら浮くか・誰が決めるか」で押す
- 数字は自社に置き換えられる形(月○時間=○人分)で見せる。抽象論で終わらせない
- 商工会議所主催のため**売り込み色は排除**。最後は「相談窓口」の案内までに留める
- 業務別パート(第3部)を最厚(18枚)にし、「うちのあの業務だ」と指を差せる状態にする
