## セミナー概要

- **タイトル**:売る時間を、取り戻す。
- **副題**:Claude Code で営業の事務作業を自動化する ─ 経営者が決める、はじめの一歩
- **対象**:中小企業の経営者・役員(商工会議所・経営者団体主催)

## この構成の前提

Claude Code は本来、技術者向けのコーディング用AIエージェント。本セミナーでは
**「ファイルを読み書きし、社内ツールとつながり、決めた作業をやり切るAI」**として、
営業まわりの事務作業(リスト作成・提案書・日報集計)を自動化する道具という位置づけで扱う。

- 経営者本人が使うツールとしては扱わない。**営業担当1名に持たせ、その人の時間を経営が確保する**という進め方を提案する構成
- 操作画面・コマンドの説明は一切入れていない。使う入口はデスクトップアプリとブラウザに限定して説明
- 第2部スライド22「使える場所は、5つ」で、ターミナル/開発環境は「経営者・営業が使う必要はない」と明示

## 登壇前に差し替え・確認が必要な箇所

| スライド | 内容 |
|---|---|
| 1, 4 | 登壇者名・所属・肩書き |
| 6, 8 | 営業の時間内訳・人件費換算(自社の営業日報の実績値へ) |
| 11 | 営業職の採用難易度の推移(登壇時点の最新統計へ) |
| 22 | **提供形態(デスクトップ/ブラウザ/スマホ/チャット連携/ターミナル)** — 変更されるため要確認 |
| 24 | 接続できるサービス(MCP)の範囲 — 利用中のサービス・社内の許可設定による |
| 25 | **価格(個人プラン月額20ドル≒約3,000円〜)** — 2026年8月時点。変更されるため登壇前に公式情報を確認 |
| 42, 46 | 削減時間・訪問件数の試算(自社規模へ) |
| 47〜49 | 事例A・B・C(想定事例。自社の導入実績があれば差し替え) |
| 64 | 公的支援制度(年度ごとに要件が変わるため要確認) |
| 70 | 主催者の相談窓口・講師連絡先 |

数値スライドには「※イメージ」「※試算例」の注記を入れてある。実データに差し替えた場合は注記も外すこと。
**特にスライド22・25は製品情報のため、開催のたびに公式ドキュメント(code.claude.com/docs、claude.com/pricing)で最新を確認すること。**
