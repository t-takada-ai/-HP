# 送信用テンプレート(ツリー投稿)

> 生成時はこの形式で出力し、確定後にヘッダ部を除いた本文を入稿ファイルとして保存する。

```
■テーマ: (ネタ帳のフック案をここに転記)
■ネタID: (例 A1)
■枠: MM/DD HH:MM
■フック型: (hook-words のどの型か)
■根拠: databank#(節)

---
【1ポスト目】
(フック1行 — hook-words の型から)

(問題提起・共感 2〜4行)

(続きを読む理由づけ 1行)

【2ポスト目】
(本題: 手順・具体例・数字)

【3ポスト目】
(本題つづき)

【4ポスト目】
(まとめ+行動喚起 or 保存を促す一言)
---
```

## 制約

- 1ポスト全角140字以内を目安(超える場合はポストを分割)
- 1ツリー3〜5ポスト
- 1ポスト目だけで価値が伝わること(2ポスト目以降が読まれなくても損させない)
- 絵文字・改行・口調は persona-voice-rules に従う
- データバンクにない数字・実績を書かない
