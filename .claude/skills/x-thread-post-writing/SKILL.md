# ツリー投稿作成スキル

## 前提

- ネタは `knowledge/ネタ帳.md` の「④選べるネタ本体」からIDで選ぶ。それ以外から作らない(CLAUDE.md 鉄則1)。
- 文体・人格は `persona-voice-rules` スキルに従う。フックは `hook-words` スキルの型を使う。
- 過去の成功パターンは `knowledge/success_patterns.md` を優先的に踏襲する。

## 手順

1. **枠の確認**
   何日の何時枠の投稿か確認する。指定がなければユーザーに確認する。

2. **ネタ選定**
   ユーザーがIDを指定していればそのID。指定がなければ、枠の時間帯に合うネタを
   ネタ帳④から2〜3候補選び、推奨1つを提示して選定する。
   選定時に必ず「②採用4条件(AND)」と「③封印リスト」を通す。
   「①使用済みネタ記録」にあるIDは候補から除外する。

3. **重複チェック(機械的に実行)**
   題材の主要キーワード+類義語で以下をgrepする:
   ```bash
   grep -niE "キーワード1|キーワード2|類義語" materials/past_posts_index.md .claude/skills/x-thread-post-writing/knowledge/past_thread_posts.md
   ```
   ヒットした場合は該当投稿と題材・切り口・結論を比較。2つ以上同じなら別IDに差し替え。
   切り口が明確に違う場合のみ、差別化ポイントを明記して続行する。

4. **生成**
   `送信用テンプレート.md` の形式で本文を作成する。
   - 1ポスト目のフックは hook-words の型から選ぶ(どの型を使ったか記録する)
   - 根拠は `materials/master_databank.md` の該当節から引く(捏造しない)
   - ネタ帳のフック案を「■テーマ」に転記してから書き始める

5. **セルフレビュー**
   誇張・根拠のない断定・データバンクにない実績の記載がないか確認する。
   persona-voice-rules のNG表現に触れていないか確認する。

6. **入稿ファイル保存**
   完成原稿を `projects/typefully_post/thread_YYYYMMDD_題材短縮名.txt` に保存する。
   (Typefully等への予約登録はユーザーの運用に従う。予約した場合はdraft URLを台帳に記録)

7. **台帳更新(必須・同一ターン内)**
   - `knowledge/ネタ帳.md` の「①使用済みネタ記録」に1行追記(使用日・ID・題材・枠・投稿No.・下書きURL)
   - `knowledge/past_thread_posts.md` に投稿No.を採番して1行追記(キーワード列を必ず埋める)

8. **完了報告**
   ID・枠・保存先パス・台帳2ファイルの更新完了を報告する。

## 完了条件

手順7の台帳2ファイルの更新まで終えて初めて「完了」。原稿だけ作って完了と報告しない。
